## Project Description

PSUT Internship Management System is a web application that helps manage the internship process for students, companies, and academic supervisors.

Students can browse internship opportunities, submit applications, view assigned tasks, submit their work, and track their progress.

Companies can manage internship opportunities, review applications, assign tasks, and evaluate student performance.

Academic supervisors and coordinators can monitor student progress and manage internship-related activities.

## Main Features

- Student, company, and academic supervisor accounts
- Internship opportunity management
- Student applications and placement tracking
- Task assignment and submission
- Training hours tracking
- Progress monitoring and evaluations
- Dashboards for different user roles

## Technologies Used

- ASP.NET Web Forms
- C#
- Microsoft SQL Server
- HTML, CSS, and JavaScript
- Bootstrap

## Getting Started

1. Clone or download the project.
2. Open the solution file in Visual Studio.
3. Configure the database connection string in `Web.config`.
4. Create or restore the required database.
5. Build and run the project using IIS Express.

## User Roles

- **Student:** Browse opportunities, apply, complete tasks, and track progress.
- **Company Supervisor:** Manage opportunities, review applications, and assign tasks.
- **Academic Supervisor:** Monitor student progress and evaluations.
- **Coordinator:** Manage students, companies, and internship placements.

## Project Structure

- `Student/` — Student pages
- `Company/` — Company and supervisor pages
- `Academic/` — Academic supervisor pages
- `Admin/` — Coordinator and administration pages
- `Content/` — CSS stylesheets
- `Scripts/` — JavaScript files
- `Assets/` — Images, fonts, and other static assets
