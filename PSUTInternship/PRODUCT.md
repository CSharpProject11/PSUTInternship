# PSUT Internship Portal

<!-- impeccable:product-schema 1 -->

## Platform
Web, ASP.NET Web Forms on .NET Framework 4.7.2, Firebase authentication and Realtime Database.

## Users
Students, company supervisors, academic supervisors, and internship coordinators.

## Product Purpose
Discover internships, apply with saved student information, review applications, and follow supervised placements.

## Brand Commitments
Preserve the supplied PSUT homepage: institutional blue, Manrope, authentic campus imagery, generous media curves and pill actions. Armenia Travel is the reference for scroll-driven film framing and draggable editorial cards. The newer Vertix dashboard screenshot is the student-workspace reference: an icon rail, spacious card grid and activity table adapted to PSUT blue, with no top navbar. Other roles retain their current workspace navigation.

## Capabilities and Constraints
Students can browse live opportunities, submit applications and confirm an offer. Use existing authenticated sessions and database rules. Never replace unavailable data with invented statistics. Supervisor and coordinator data may be unavailable under the current rules; show that state clearly. Dashboard design does not authorize changing Firebase access rules or creating new administrative write operations.

## Accessibility
Keyboard navigation, explicit carousel controls, reduced motion, pausable video, responsive layouts, visible focus and readable contrast.
