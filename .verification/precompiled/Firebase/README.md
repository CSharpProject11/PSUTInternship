# Firebase setup

All roles use `FirebaseDatabaseUrl` and `FirebaseWebApiKey` from `../Web.config`. There are no hardcoded company IDs or per-page projects.

Use `database.rules.example.json` as the single rules template. The repository README describes coordinator bootstrap, profile UIDs, collection paths, schema compatibility and coordinator link synchronization, configurable assessment policy and verification. Rules and database exports are not deployed automatically.
